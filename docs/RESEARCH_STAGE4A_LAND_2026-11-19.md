# R01 — Этап 4А: однократная геологическая переоценка земли

**Статус:** реализовано в отдельной PR-ветке, выпуск всей системы исследований будет только после этапов 4Б–10. Не считать активной механикой текущего `main`.

## Утверждённое правило

После успешного финансирования R01 один раз изменяется **текущая** стоимость участков (Land Value) города:

- На −1: Marina, Financial District, SoMa, Mission, Mission Bay.
- На +1: Pacific Heights, Chinatown.
- Значения ограничены 0–6. Если район уже у границы, цена не выходит за пределы.
- Уже уплаченная за строительство земля **не пересчитывается**, возвратов и доплат за ранее открытые стройки нет.
- Эффект общегородской: любые игроки оплачивают **будущую** землю по новой цене. Последующие законные изменения Land Value действуют как обычно.

Данные районов и величина эффекта читаются из `research-cards.js::R01.effect`. Никаких отдельных пользовательских массивов, новых земельных цен или изменений базового каталога `DISTRICTS` нет.

## Техническая реализация и P22

`game-core.js` содержит `RESEARCH_INSTANT_FUNDING_PREPARERS`, реестр подготовщиков для разовых эффектов в момент финансирования. R01 регистрирует тип `land-revaluation-once`; подготовщик:

1. Проверяет диапазон, все ID районов, отсутствие повторного ID, численность текущих значений и дельты.
2. Без мутации рассчитывает план семи изменений. `researchFundingPreview` показывает этот план, но не применяет его.
3. Только если пройдены **все** условия финансирования и корректен план, `fundResearch` списывает деньги, выдаёт личную награду, переводит карточку в `funded` и применяет план через существующий `setLandValue`.
4. Уже `funded` карта не может быть профинансирована снова даже после reload, поэтому второй переоценки и второй награды нет.

**Расширение:** следующая карта с новым немедленным эффектом добавляет свой подготовщик по `effect.type` без ветвления в `fundResearch` по ID. Отложенные постоянные/условные эффекты R02–R08 подключаются через собственные точки в движке, не выдаются за реализованные и не должны притворяться немедленными эффектами.

## Тестирование

`tests/research-r01.test.mjs`, включён в явный список `npm run test:core`:

- Превью без мутации, удерживаемая карта не влияет на цены; строго пять вниз / два вверх, остальные районы без изменений.
- Живые изменения до открытия R01, значения 0 и 6, независимость исходного реестра `DISTRICTS`.
- Реальное `beginConstruction` **до** открытия R01 и **после** открытия R01; отсутствие возврата за ранее купленную землю.
- Реальное получение → финансирование без второго рабочего; спонсорская награда и эффект во всём городе.
- Повторное финансирование и JSON reload, чужая/свободная карта, недостающие деньги, неверная фаза/ход, некорректный Land Value — без частичной мутации.
- Финансирование иной карты не запускает R01; дальнейшие изменения цены не блокируются; финансирование в шестом году не запрещено.
