# San Francisco 1906 — отклонённые идеи и причины

**Назначение:** не предлагать вновь механики, от которых пользователь уже отказался. Подробные формулировки проверять по первичным источникам; некоторые основания восстановлены из доступной истории обсуждений (обозначено как «обсуждение»), поэтому не приписывать им недоказанные параметры.

**Важно:** «отклонено», «заменено» и «отложено» — РАЗНЫЕ статусы. В разделе «Отложено» идеи допускаются после разработки зависимостей; не называть их навсегда запрещёнными. Для обычной критики предложенных вариантов без окончательного отказа используйте **[DESIGN_FEEDBACK.md](DESIGN_FEEDBACK.md)**, а не расширяйте этот список запретов.

## C. Особые предупреждения, чтобы не возвращать старые ошибки

1. **Статус документа — дата снимка, а не вечная истина.** Заметка от 21.10 пишет «матросы не внедрены»; PR #37 того же дня уже внедрил механику. Сверяться с [реестром](buildings-master-registry.md).
2. **R06 переиспользован.** Бывший трамвайный R06 из [старого документа](research-r06-redesign.md) НЕ текущая R06 из [research-cards.js](../research-cards.js). Текущий R06 — «Муниципальное финансирование подрядов».
3. **Не переносить R03=3 пожарных учреждения из старого обсуждения.** В данных от 17.10 действующее для дизайна условие — **2**. Пока исследование не внедрено, не выдавать его за рабочее правило.
4. **Не восстанавливать PR #25** только потому, что он был merged: его полностью отменили PR #26; актуальная ограниченная многоточечная погрузка — PR #27.
5. Любую отклонённую идею можно пересмотреть **только по явному запросу пользователя или новым веским аргументам**, сначала указав, что это пересмотр и почему причины старого отказа больше не действуют.

## D. Как пополнять файл

Добавлять после явного отказа: дата, точная старая механика, причина, **что заменило**, ссылка на источник, статус «отклонено/заменено/отложено». Не превращать просто «не выбрали из трёх» в пожизненный запрет. При последующем пересмотре оставлять запись и ссылаться на новое решение в [DECISION_LOG.md](DECISION_LOG.md).
