# F03 — «ПОЖАР ПАРАЛИЗОВАЛ ОДИН ИЗ ПОРТОВ ГОРОДА!»

**Статус:** утверждённый пользователем 11.11.2026 дизайн для первого плейтеста. **Не реализован** в движке/UI: в `newspaper-cards.js` — только неисполняемое `designV2`, старый эффект F03 сохраняется.

## Газетная карточка — итоговый короткий текст

**THE SAN FRANCISCO CALL · F03 · ПОЖАР**

### ПОЖАР ПАРАЛИЗОВАЛ ОДИН ИЗ ПОРТОВ ГОРОДА!

*Крупный пожар уничтожил складские помещения одного из портов Сан-Франциско! Разгрузка судов остановлена, а торговые компании вынуждены срочно перенаправлять грузы на другие причалы. Городские перевозчики готовятся к перебоям в снабжении.*

**ПОСТРАДАВШИЙ ПОРТ**

Бросьте D6:

| D6 | Порт |
| --- | --- |
| 1 | Broadway Wharf |
| 2–3 | Pacific Mail |
| 4–5 | China Basin |
| 6 | Potrero Point |

**ПЕРЕРАСПРЕДЕЛЕНИЕ ПОСТАВОК**

В этом году пострадавший порт не получает материалов. Весь его обычный запас перенаправляется в остальные порты.

Случайно выбирайте по одному материалу из запаса закрытого порта и размещайте в работающих портах по порядку:

**Pacific Mail → China Basin → Broadway Wharf → Potrero Point**

Пропускайте закрытый порт. Если материалы остались, повторяйте порядок с начала.

## Технические и дизайнерские границы

- **Временное событие лишь текущего года**: это свойство стандартной обработки газетных событий, поэтому **не повторяется отдельным блоком «Продолжительность» на самой карточке**. На следующий год стандартное пополнение узлов без этого эффекта.
- **Только четыре морских узла** участвуют в розыгрыше и перераспределении: Broadway Wharf (обычный запас 3), Pacific Mail / Pier 40 (4), China Basin / ATSF (4), Potrero Point / Union Iron Works (2). Южная железная дорога **Southern Pacific / Third & Townsend (4)** не горит и не принимает перенаправленные портовые материалы.
- D6: 1 — `broadway`; 2–3 — `pacificmail`; 4–5 — `chinabasin`; 6 — `unioniron` (порт Potrero Point). Вероятности намеренно различаются: 1/6, 2/6, 2/6, 1/6.
- При обычном пополнении **сначала сгенерировать** весь предусмотренный запас каждого из четырёх портов по его обычным вероятностям материалов. Затем перенести **все фактически сгенерированные** кубики из выбранного сгоревшего порта: в случайном порядке по одному (перемешать содержимое этого запаса), в **строгой циклической очереди работающих портов** из базовой последовательности `pacificmail → chinabasin → broadway → unioniron`; вычеркнуть закрытый и повторять порядок до исчерпания кубиков. Закрытый порт остаётся без материалов.
- Приоритет определён по **обычному объёму перевалки 4, 4, 3, 2**. При равной вместимости порт выше на карте (Pacific Mail) идёт перед расположенным южнее (China Basin). Начинать каждый цикл с **первого открытого порта списка**, а не с соседнего сгоревшему.
- **Не создавать и не уничтожать ресурсы:** сохраняются точные типы кубиков, полученные при генерации; суммарно узлы города сохраняют обычные **17** материалов (13 портовых +4 железнодорожных), независимо от закрытого порта. Принимающий порт может временно иметь запас **выше обычной вместимости/объёма пополнения**.
- Применить эффект **при начальном пополнении года после определения газетного события**, не изымать уже купленные/перевезённые материалы. `game-core.js` сейчас выбирает газету до `refreshLogisticsSupply` при смене года и до первичного создания `logisticsSupply`; оба случая требуют тестирования при будущем подключении.
- Не назначать игрокам новых штрафов, наград, действий тушения, маршрутов для обхода закрытого узла, изменения цен нейтральных поставщиков, дохода владельцам портов или дополнительных жетонов. Порт не становится недоступным районом: **пустеет только его логистический запас**.
- F03 отличается от утверждённой H03: **H03 уменьшает общий объём поставок из морских узлов**, F03 **сохраняет общий объём, но меняет географию ресурсов**. Не переносить санкции H03 и legacy-штраф F03 на эту карточку.

## Проверки для будущего игрового PR

- Верное соответствие D6 и названий/ID четырёх узлов; оба пути генерации: 1900 и последующие годы.
- Закрытый порт получает 0; Southern Pacific неизменен; типы и общая численность 17 сохранены при любом результате D6.
- Очередность каждого дополнительного кубика для всех четырёх закрытых портов, в том числе повторные круги и одинаковая ёмкость двух крупных портов; большой запас принимающего порта разрешён.
- Нет срабатывания в другие годы, нет дополнительных действий и наград, нет повторного перераспределения при сохранении/загрузке, без старых legacy-санкций после внедрения.
- Профильные тесты `npm run test:core` и `npm run test:e2e` обязательны при будущем изменении кода по `docs/TESTING_POLICY.md`. Настоящий PR — только документационный.
