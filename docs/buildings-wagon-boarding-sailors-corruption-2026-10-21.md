# SF1906 — зафиксированные концепты: вагонный пансион, матросская ночлежка и коррупция

**Дата фиксации:** 2026-10-21  
**Статус:** дизайн двух карт сохранён для дальнейшей реализации/тестов. **Не внедрён в game-core.js, app.js, колоду или интерфейс.** Утверждённые пользователем принципы отделены от предварительных чисел/граничных правил.

## A. Утверждённые пользователем решения

1. Подготовить **две отдельные карты**, обе смешанной категории **Жилое + Бизнес**: вагонный пансион западных окраин (историческая основа — Carville-by-the-Sea / Vista del Mar) и матросская ночлежка при портах (историческая основа — sailor boarding houses, crimping/shanghaiing). Не отбрасывать одну ради симметрии плана «по одной карте на смешанную пару».
2. **Обе карты строятся только из Lumber**, без Masonry и Steel. Цель — повышать спрос на дерево относительно чрезмерного использования Masonry в текущей колоде.
3. **Вагонный пансион:** 3 уровня развития; уровни I/II/III при **перестройке** дают соответственно **1/2/3 Lumber** для нового здания. Сначала пансион — источник дохода, затем по желанию расширяется, потом заменяется другим проектом.
4. **Повышение уровня пансиона — быстрое действие без траты основного действия рабочего** (не требовать выбирать или перемещать рабочего специально ради улучшения). **Перестройка пансиона в другое здание — полноценное основное действие рабочего** с обычной проверкой достижимости района.
5. **Коррупция:** одна персональная шкала **«Коррупция»** у каждого игрока/его **офиса**; не одна общая величина для города и **не шкалы отдельных рабочих**. Во всех текстах называть именно «Коррупция»: показатель растёт или снижается от соответствующих действий. Для первого прототипа верхнее значение **3** (диапазон **0–3**).
6. Жалобы в полицию, расследования, использование СМИ/компромата для снижения влияния соперника — **только идеи для будущей системы**. **СЕЙЧАС НИЧЕГО ИЗ ЭТОГО НЕ РЕАЛИЗОВЫВАТЬ**, не вводить автоматических штрафов по шкале коррупции.
7. Если отдельная коррупция сделает игру избыточно сложной, для матросской ночлежки предусмотрен **fallback: незаконный эффект вместо повышения коррупции уменьшает Political Influence**. Величина потери ещё не утверждена.
8. Расположение шкалы в физической/цифровой игре ещё не выбрано: возможно, личные шкалы в офисах или **одна общая графическая дорожка с тремя цветными маркерами** игроков на общем поле; в любом случае значения остаются **раздельными по игрокам**, а не глобальным единым значением.

## B. Карта 1 — «Вагонный пансион» (рабочее имя: «Виста-дель-Мар»)

- **Типы:** Жилое + Бизнес.
- **Тема:** бывшие трамвайные вагоны объединяют в дешёвые жилые корпуса, сдают жильцам, а позднее конструкции повторно используют для другого строительства.
- **Твёрдо утверждено:** строительство только из Lumber; 3 уровня; доход увеличивается при расширении; быстрое улучшение **без рабочего**; перестройка **за основное действие рабочего**; уровень I/II/III возвращает в новый проект **1/2/3 Lumber**.
- **Параметры для первого балансового теста (ещё не подтверждены окончательно):**
  - Начальное строительство **2 Lumber**, 0 VP; стартовая цена карточки/аукциона **$3**.
  - Уровень I: доход **$1/год**, П **+1**, возможная древесина при перестройке **1 Lumber**.
  - Уровень II: доход **$2/год**, П **+2**, при перестройке **2 Lumber**.
  - Уровень III: доход **$3/год**, П **+3**, при перестройке **3 Lumber**.
  - Каждое улучшение **$2**. Предварительное ограничение — **не более одного повышения уровня данного пансиона в игровой год**, быстрое действие в собственную активацию без рабочего и без требования его присутствия в районе.
  - **У0** от самого пансиона (тестовое значение).
  - География: запад Сан-Франциско; кандидаты **Outer Sunset, Inner Sunset, Outer Richmond, Inner Richmond**. Историческая привязка Vista del Mar — Outer Sunset. Точный список допустимых районов ещё согласовать.
- **Предлагаемый механизм перестройки, подлежащий тестам:**
  1. В свой ход выбрать подходящий проект здания в портфеле и рабочего, который вправе действовать в районе пансиона.
  2. Использовать **основное действие строительства/перестройки**; убрать старый пансион с участка, его доход и риск более не действуют.
  3. Новый проект занимает тот же участок, **повторно не платить за землю**; соблюдать остальные требования нового проекта. Предлагается разрешить **любой** тип нового здания, не только Жилое (ещё подтвердить).
  4. Засчитать `min(уровень пансиона, число Lumber в требованиях нового проекта)` древесины сразу **в эту стройку**, без физической перевозки. Излишек не выдавать на руки и не хранить.
  5. Остальные материалы нового проекта доставляются по обычной логистике. **Ограничение стройплощадки 3 и требования к складу сохраняются**; не создавать обход многоматериальных проектов.
  6. Перестройка не возвращает карту старого пансиона в руку и не создаёт свободные ресурсы после его сноса.
- **Отдельно протестировать:** не становится ли связка бесплатного по рабочим улучшения, отсутствия повторной платы за землю и возврата 3 Lumber чрезмерно сильной; не является ли стоимость $2 слишком низкой.

## C. Карта 2 — «Матросская ночлежка»

- **Типы:** Жилое + Бизнес.
- **Тема:** дешёвое массовое проживание моряков и участие владельца в найме экипажей, включая незаконную/принудительную вербовку.
- **Твёрдо утверждено:** существует отдельной картой; **только Lumber** для строительства; криминальный эффект важнее пассивного портового бонуса; коррупционные действия приносят деньги и повышают личную **Коррупцию** владельца.
- **Параметры первого теста (не окончательный баланс):**
  - Строительство **3 Lumber**; доход **$1/год**, **0 VP**, риск от здания **У+1, П+2**.
  - Нужен **действующий обычный портовый узел погрузки** в районе (не любой тег `port` и не экспортный Gas House Cove).
  - **Раз в год** после успешно завершённой доставки с погрузкой материалов в этом портовом узле, сделанной **любым игроком**, владелец выбирает один эффект:
    - **Законный найм:** **+$2** из банка, коррупция не меняется.
    - **Незаконная вербовка:** **+$6** из банка, **Коррупция +1** у владельца.
  - При текущем значении коррупции **3** повторно повышать её нельзя; для теста незаконная вербовка недоступна, доступен законный вариант. Никаких **автоматических штрафов, арестов или активации полиции** без отдельно утверждённой системы.
  - Портовый триггер один за игровой год для каждой ночлежки, **не за каждый куб материала**, чтобы не возникала бесконечная прибыль от многоточечных маршрутов.
- **Fallback без шкалы коррупции:** незаконная вербовка повышает краткосрочную прибыль, но уменьшает **Political Influence** на согласованную позднее величину (не подставлять число без согласования).
- **Проверить баланс:** +$6 в ранние годы при отложенном наказании; насколько стабильно срабатывает триггер при низкой/высокой портовой активности; наличие портов одновременно усиливает уже прибыльный восток.

## D. Коррупция: записано, но не реализуется

- Термин UI и правил: **Коррупция**, диапазон **0–3** на игрока.
- Значение принадлежит **игроку / офису**, не конкретному объекту, району, рабочему или городу.
- Пока **нет** функций жалобы, расследования полиции, публикации компромата, штрафов, пересмотра влияния или специальных правил уменьшения коррупции.
- Возможные направления **на будущее**, без утверждения эффектов: право конкурента подать жалобу в полицейский участок; проверка коррупционного бизнеса; разоблачение в газете с потерей Political Influence; возможность уменьшать коррупцию. Ничего не добавлять к текущему игровому циклу автоматически.
- Дизайн UI при реализации выбирать отдельно: читаемое число на офисе игрока и, возможно, компактный индикатор в верхнем HUD; физически возможна одна дорожка на общем поле с тремя маркерами (это способ **отображения трёх отдельных показателей**).
